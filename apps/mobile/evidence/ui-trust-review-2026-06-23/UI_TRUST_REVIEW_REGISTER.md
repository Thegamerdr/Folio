# UI Trust Review Register

Canonical register lives at the repository root:

`UI_TRUST_REVIEW_REGISTER.md`

This evidence-folder copy points to the root file to avoid maintaining two diverging registers. The root register contains:

- evidence reviewed
- surface scores across the required trust dimensions
- P0/P1/P2/P3 issue classification
- fixes made
- dogfood readiness decision

After-fix screenshots are in `after-screenshots/` and `after-screenshots-contact-sheet.png`.
