# Release Blocker Register

Canonical source: `RELEASE_BLOCKER_REGISTER.md`.

Evidence summary:

- Owner dogfood blockers are separated from external beta and public release blockers.
- Owner Android dogfood remains private/internal; public release blockers do not falsely fail it.
- External beta is blocked by physical dogfood results, iOS proof, security, accessibility, privacy/legal and support evidence.
- Public release is blocked by store declarations, billing, independent reviews, iOS release proof, cloud/account deletion, operations and legal/privacy signoff.
- The register marks which blockers need Windows, Android device, macOS/Xcode and legal/business decisions.
