# IA Before And After

Date: 2026-06-24

## Before

The app exposed too many equal starting points:

- Today
- Timeline
- Calendar
- Plans
- Melo
- Money
- Import Review
- Data Control
- Dogfood Mode
- Recovery

This made internal structure compete with the user path.

## After

Primary navigation is now:

- Start
- Review
- Today
- More

More contains:

- Timeline
- Calendar
- Plans
- Data Control
- Dogfood Mode
- Settings-style local controls

## User Path

The app now points the user toward:

1. Start with what you have.
2. Review what Folio found.
3. See your picture.

Timeline, Calendar and Plans remain available, but they are no longer front-door choices for a new user.
