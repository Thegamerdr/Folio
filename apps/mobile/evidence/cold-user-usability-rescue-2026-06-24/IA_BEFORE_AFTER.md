# IA Before And After

Date: 2026-06-24

## Before

Fresh/no-data launch could send the user into the old first-minute rehearsal. Start also carried too many implied starting methods and old labels such as sample/manual/import wording that sounded like implementation flows.

Primary and secondary concepts competed:

- Timeline
- Calendar
- Plans
- Melo
- Money
- Import Review
- Data Control
- Dogfood Mode
- Recovery

## After

Fresh/no-data launch opens Start.

Primary navigation is:

- Start
- Review
- Today
- More

Start shows only:

- Use a bank statement
- Paste transactions
- Add a few numbers
- Try fake data

More contains Timeline, Calendar, Plans, Review rows, Data and privacy, Internal test mode and settings-style local controls.

## Product Effect

The app now begins with a user decision, not an implementation explanation. Review is the explicit gate before rows affect Today.
