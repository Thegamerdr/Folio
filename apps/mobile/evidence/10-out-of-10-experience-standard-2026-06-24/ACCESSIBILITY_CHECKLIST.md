# Accessibility Checklist

Date: 2026-06-24

## Improved

- Lens choices are buttons with selected state.
- Primary actions retain minimum tap target sizing through existing button components.
- Manual input questions include accessible question text and why text.
- Amount inputs use decimal keyboard hints.
- Date inputs keep explicit labels and date-format hints.
- Review action buttons explain consequences through accessibility hints.
- Route points expose a Show why reveal with source, action and review context.
- Waiting review state is not colour-only; copy and badges name the state.
- Unsupported file paths provide explicit manual alternatives instead of dead-ending.
- Bottom navigation remains Start, Review, Today and More.

## Still Needs Real Device Review

- VoiceOver and TalkBack reading order on the lens grid.
- Large text wrapping on the longest lens labels.
- One-handed comfort on the guided manual path.
- Native date input comfort.
- Reduced-motion route behaviour beyond the existing preference hook.
- Real-device frame pacing for route and review-heavy screens.
