# Known Limitations

- Physical Android owner testing has not been performed by this agent.
- Dogfood Mode is an internal/test harness, not a production settings surface.
- Diagnostic export is not a full user data export.
- Business UI is intentionally not built.
- Cloud sync is intentionally not built.
- Open Banking is intentionally not built.
- AI gateway and final Melo runtime are intentionally not built.
- Billing is intentionally not built.
- OCR pipeline is intentionally not built.
- Pulling app files with `run-as` may be unavailable on some release builds; use phone file access where needed.
