# Android Owner Dogfood Script

Canonical script: `ANDROID_OWNER_DOGFOOD_SCRIPT.md` at the repository root.

Run order:

1. Install APK.
2. Open clean app.
3. Record first emotional reaction.
4. Run empty first launch.
5. Try sample briefing.
6. Reset.
7. Run minimal manual path.
8. Restart app.
9. Run import review scenario.
10. Accept, edit or reject.
11. Check Today.
12. Check Timeline.
13. Check Calendar.
14. Check Plans/Recovery.
15. Accept recovery.
16. Check Data Control.
17. Export diagnostic bundle.
18. Record bugs.

For each step, capture what was tapped, what happened, screenshot path, bug status and the emotional question answer.
