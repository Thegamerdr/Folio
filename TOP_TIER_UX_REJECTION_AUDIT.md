# Top-Tier UX Rejection Audit

Date: 2026-06-24

This audit rejects the previous real-product UX pass as insufficient. The screens were clearer than the earlier prototype, but several still looked like a structured demo of the system instead of a mobile product a cold, stressed user would want to continue using.

| Screen                  | Verdict | Why it fails or only partially passes                                                                                                  | User emotion created                          | Top-tier version should do                                                                                                                    | Change needed                         |
| ----------------------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| Start                   | Fail    | It presented several cards with near-equal weight and copy about how Folio works. The first useful action was not visually inevitable. | "Which option am I supposed to pick?"         | Lead with one first-win promise, one dominant recommended action, demoted secondary paths and a safety line.                                  | Full layout and copy rebuild.         |
| Guided manual input     | Fail    | The stepper existed, but it still felt like a finance form inside a card. It used system-anchoring language and weak input presence.   | "This is homework."                           | One question per screen, large input, estimate/skip controls, hidden note, progress and immediate picture preview.                            | Interaction, copy and visual rebuild. |
| Import entry            | Partial | The entry path was honest about CSV/text and unsupported files, but it still looked like a panel of technical choices.                 | "Maybe this works, maybe not."                | Make the safe import path clear: paste or choose file, then review rows before anything changes.                                              | Copy and hierarchy change.            |
| PDF/screenshot fallback | Partial | It was honest that automatic reading is not ready, but the action area still felt basic and utilitarian.                               | "At least I am not stuck, but this is rough." | Show the file is kept, say exactly what can be done next, and provide manual extraction actions plus remove/keep.                             | Layout and action hierarchy change.   |
| Review rows             | Fail    | Actions were visible under rows as a dense action cluster. That is not a premium row-by-row mobile decision experience.                | "This is a control panel."                    | Each row is a decision object; tapping it opens a bottom sheet with Add/Edit/Ignore/Duplicate/Transfer/Refund/Income/Bill/Debt payment/Later. | Interaction rebuild.                  |
| Today                   | Partial | It surfaces real money state and review separation, but supporting copy can still read like product mechanics.                         | "Useful, but still explaining itself."        | Keep the answer direct: what is available, what is coming up, what changed, what needs checking.                                              | Copy and hierarchy polish.            |
| Breathing-room route    | Fail    | The line chart looked too decorative and did not foreground dates, buffer, lowest point and causes strongly enough.                    | "Pretty graph, but what am I meant to learn?" | A pressure map answering will I make it, when do I run tight, what caused it, what improves it and what still needs review.                   | Full route composition rebuild.       |

| Data/privacy            | Partial | It is honest about local records and clearing, but some copy still explains record structure.                                          | "I can trust this, but it is wordy."          | Focus on what is here, what can leave, what can be cleared and what nothing means.                                                            | Copy trim and visual polish.          |

Manual quality answers before rebuild:

1. Does this still feel like a form? Yes, especially guided input, debt and bills.
2. Does this still feel like a calculator? Partly, because numeric input is visually small and boxed.
3. Does Start feel like a first win or a menu? Menu.
4. Are row actions attached to rows? Partly attached visually, but not as a focused mobile interaction.
5. Does the route answer a real question? Not strongly enough; it gestures at the answer.
6. Is the copy human or system-like? Mixed; several phrases still sound like product documentation.
7. Would a cold user know what to do? Maybe on Start, but not with enough confidence.
8. Would a stressed user continue? Not reliably.
9. Would the owner still want to uninstall after 10 minutes? Risk remains.
