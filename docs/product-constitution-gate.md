# Product Constitution Gate

Every change must preserve the source package constitution:

- local-first core without account, internet, bank feed or AI;
- consequence language instead of personal financial advice;
- integer minor-unit money with explicit currency;
- personal/business separation below the UI;
- authoritative facts separated from expectations, projections and hypotheticals;
- Melo and automated adapters submit proposals or typed commands only;
- no shame, guilt streaks, fabricated health scores or dark engagement loops;
- accessibility, export and recovery are release properties, not polish.

The pull-request template carries the operational checklist. `pnpm check:constitution` blocks CI if the gate is removed.
