# Melo Store Reviewer Notes

## Status

Draft only. These notes are not submitted store-review text.

## Required Reviewer Notes

- Melo works locally without an account for the personal core.
- Reviewer data is synthetic and clearly labelled.
- Melo organises and explains user-provided financial records; it does not execute transactions,
  recommend regulated products or file taxes directly.
- Optional cloud, AI, Open Banking, business and billing features must be described only if enabled
  in the submitted binary.
- Account deletion, export and support/privacy URLs must be provided when account or cloud features
  are enabled.
- Any demo account credentials or review access must be current and must not expose real financial
  records.

## Current Melo Position

- A signed Android release candidate, public privacy/terms/deletion/support URLs and synthetic
  demo data exist.
- The personal core is reviewable without account creation. Optional sign-in, backup, Open
  Banking and billing must be exercised only when their production provider is configured.
- No submitted Play binary or store-console review evidence exists yet.
