# Accessibility Notes

## Improved In This Pass

- First-minute primary actions have explicit labels and hints.
- Sample labels are accessible as separate non-user-data markers.
- Today answer surface describes the amount, state and source summary.
- Timeline legend gives row categories before the list.
- Import Review guide announces action consequences before row-level choices.
- Data Control export and ownership counts are grouped into accessible panels.
- Melo boundary text tells users changes still need review.
- Recovery path copy is accessible as one concise review-before-saving panel.

## Still Needs Device Verification

- VoiceOver and TalkBack traversal.
- Large text wrapping on small Android devices.
- Switch/keyboard traversal.
- Native safe-area edges.
- Native document picker focus return.
- Export file handoff behaviour on iOS and Android.
