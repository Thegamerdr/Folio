# Folio Data Protection Impact Assessment Template

## 1. Project and owner

- Product/version:
- Assessment owner:
- DPO/privacy counsel:
- Date/review date:
- Countries/users:
- Processing phase: design / beta / launch / change.

## 2. Processing summary

Describe local and optional cloud processing for:

- financial records and forecasts;
- documents/OCR;
- Melo conversations/memory;
- encrypted backup/sync;
- AI providers;
- Open Banking;
- business/tax records;
- diagnostics/analytics.

## 3. Data inventory

For each category record: source, purpose, lawful basis, local/cloud location, processor, retention, recipient, AI use, deletion/export path and sensitivity.

## 4. Necessity and proportionality

- Why is each field needed?
- Can processing remain on-device?
- Is account creation avoidable?
- Is cloud processing opt-in and scoped?
- Are less intrusive alternatives available?
- How are users informed and given control?

## 5. People and risks

Consider:

- financial anxiety/vulnerability;
- lost/stolen/shared device;
- coercive control;
- personal/business mixing;
- model inference/hallucination;
- provider breach;
- recovery failure;
- inaccurate financial/tax output;
- children or age uncertainty;
- international transfers;
- re-identification from telemetry.

## 6. Risk assessment

For each risk: likelihood, severity, affected rights, existing controls, additional actions, owner, due date and residual risk.

## 7. Safeguards

- SQLCipher and file encryption;
- Keychain/Keystore and recovery design;
- data minimisation;
- no ads/tracking;
- typed AI proposals;
- workspace isolation;
- consent dashboard;
- export/deletion;
- accessibility and plain language;
- processor contracts;
- incident response.

## 8. Consultation

Record legal/security/accessibility/user research, vulnerable-user review, processor review and any ICO consultation if residual high risk remains.

## 9. Decision

Approve / approve with actions / reject. Name accountable approver and review triggers.
