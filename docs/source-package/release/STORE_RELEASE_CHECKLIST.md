# App Store and Play Store Release Checklist

## Product behavior

- [ ] Local personal core works without login.
- [ ] Demo uses synthetic labelled data only.
- [ ] Advice/tax claims match legal review.
- [ ] All submitted features are complete and reviewable.
- [ ] Business mode declaration matches binary scope.

## Accounts

- [ ] In-app account deletion works.
- [ ] Google web deletion route works.
- [ ] Sign in with Apple parity reviewed if third-party login exists.
- [ ] Cloud deletion versus local retention is explained.
- [ ] Purchase restore and entitlement grace tested.

## Privacy

- [ ] Privacy policy and processor list current.
- [ ] Apple App Privacy answers match code.
- [ ] Privacy manifests/required-reason APIs complete.
- [ ] Google Data Safety form complete.
- [ ] Financial Features declaration complete.
- [ ] No undisclosed SDK collection.
- [ ] DPIA approved.

## Permissions

- [ ] Every permission is just-in-time and purpose-specific.
- [ ] Denial fallback works.
- [ ] Lock-screen notification privacy defaults verified.
- [ ] Calendar read versus write-only access accurate.

## Technical quality

- [ ] Production database/crypto build verified.
- [ ] Offline E2E suite passes.
- [ ] Migration/backup/restore passes.
- [ ] Accessibility critical paths pass.
- [ ] Crash/performance targets met.
- [ ] Store SDK/target API requirements current.
- [ ] No test keys or financial fixtures in release.

## Review notes

- [ ] Explain local-first/no-account mode.
- [ ] Explain Folio simulates and organises; it does not recommend products or execute regulated advice.
- [ ] Supply demo instructions and any regulated provider evidence.
- [ ] Supply support/privacy/account-deletion URLs.
