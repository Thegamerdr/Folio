# V1 Donor Audit

No V1 donor material has been used.

Before any V1 reference is inspected or imported, record:

- source path, screenshot or asset;
- category: reuse unchanged, adapt deliberately, reference only or reject;
- why it fits V2;
- domain coupling and licence/provenance;
- approval;
- V2 destination.

V1 source must remain outside the V2 runtime tree. Coupled V1 database, routing, state management and dashboard assumptions are rejected unless a future approved donor record says otherwise.
