Folio V2 · the first minute

Do not onboard the user. Let them feel the relief first.

The empty state earns curiosity, a tiny playable example proves the idea, import turns into visible discovery, and the first real answer arrives as soon as the system knows enough—not when every field is complete.
The behavioural move: value before methodology. No financial profile, no shame, no “complete 12 steps.” Each question exists because it unlocks the next useful answer.
